# Survey API — Сервис опросов и голосований

**Проект:** Survey API  
**Стек:** Node.js + Express.js + MySQL  
**Автор:** Abubachir22

---

## Описание проекта

Survey API — это REST API для создания и управления опросами. Система позволяет авторам создавать опросы с различными типами вопросов (одиночный выбор, множественный выбор, текстовый ответ), публиковать их и собирать ответы от респондентов. Авторы могут просматривать аналитику по результатам опросов.

## Реализованные чекпоинты

- ✅ **Чекпоинт 1:** Проектирование и старт  
  ER-диаграмма, список эндпоинтов, миграции, структура проекта.

- ✅ **Чекпоинт 2:** Авторизация и базовый CRUD  
  Регистрация и авторизация (JWT), CRUD опросов, управление вопросами и вариантами, валидация.

- ✅ **Чекпоинт 3:** Основная бизнес-логика  
  Жизненный цикл опросов (draft → published → closed), прохождение опросов, валидация ответов, защита от повторного прохождения, аналитика.

- ✅ **Чекпоинт 4:** Продвинутый функционал  
  Пагинация, фильтрация (мои / активные / завершённые), сортировка списка опросов, расширенная аналитика.

- ✅ **Чекпоинт 5:** Тесты, Swagger, Docker  
  Автотесты (Jest + Supertest), Swagger UI по `/api/docs`, Dockerfile и docker-compose для запуска одной командой.

- ✅ **Чекпоинт 6:** Финализация и защита  
  Актуализирован README, чеклисты и документация, подготовка к демонстрации проекта.

## Быстрый старт

### Требования

- Node.js (v14 или выше)
- MySQL (v5.7 или выше)
- npm

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd src
   ```

2. **Установите зависимости**
   ```bash
   cd src
   npm install
   ```

3. **Настройте переменные окружения**
   
   Создайте файл `src/.env`:
   ```
   PORT=3000
   NODE_ENV=development
   DB_HOST=localhost
   DB_PORT=3306
   DB_NAME=survey_db
   DB_USER=root
   DB_PASSWORD=your_password
   JWT_SECRET=your-secret-key-change-in-production
   JWT_EXPIRES_IN=7d
   ```

4. **Создайте базу данных**
   ```sql
   CREATE DATABASE survey_db;
   ```

5. **Запустите миграции**
   ```bash
   cd src
   npm run migrate
   ```

6. **Заполните тестовыми данными (опционально)**
   ```bash
   npm run seed
   ```

7. **Запустите сервер**
   ```bash
   npm start
   ```

Сервер будет доступен по адресу `http://localhost:3000`

Подробная документация находится в [`src/README.md`](./src/README.md)

## API Endpoints

### Аутентификация
- `POST /api/auth/register` — Регистрация
- `POST /api/auth/login` — Вход
- `GET /api/auth/profile` — Профиль

### Опросы
- `POST /api/surveys` — Создать опрос
- `GET /api/surveys` — Список опросов (поддерживает пагинацию и фильтры)
  - Query параметры:
    - `page` — номер страницы (по умолчанию `1`)
    - `limit` — количество элементов на странице (по умолчанию `10`, максимум `100`)
    - `status` — фильтр по статусу (`draft`, `published`, `closed`)
    - `mySurveys` — только мои опросы (`true` / `false`)
    - `filter` — преднастроенные фильтры: `active` (опубликованные), `completed` (закрытые)
    - `sortBy` — поле сортировки: `createdAt` (по умолчанию), `responsesCount`
    - `sortOrder` — `asc` или `desc` (по умолчанию `desc`)
- `GET /api/surveys/:id` — Получить опрос
- `PUT /api/surveys/:id` — Обновить опрос
- `DELETE /api/surveys/:id` — Удалить опрос
- `POST /api/surveys/:id/publish` — Опубликовать
- `POST /api/surveys/:id/close` — Закрыть

### Вопросы и варианты
- `POST /api/surveys/:surveyId/questions` — Добавить вопрос
- `POST /api/surveys/:surveyId/questions/:questionId/options` — Добавить вариант

### Ответы
- `POST /api/surveys/:surveyId/responses` — Отправить ответы
- `GET /api/surveys/:surveyId/analytics` — Аналитика (количество и процент по вариантам, текстовые ответы)

### Документация API
- `GET /api/docs` — Swagger UI с интерактивной документацией

Полная документация: [API_ENDPOINTS.md](./docs/API_ENDPOINTS.md)
